# SimpleTarot - 🔮 塔罗占卜工具

一个轻量级的、交互式的塔罗牌在线占卜工具，结合了传统的塔罗占卜流程与人工智能（AI）深度分析。

## ✨ 功能特点

- 🔮 **多种牌阵选择**：支持单张牌、三张牌、五张十字、二选一、六芒星、七张马蹄、凯尔特十字及关系牌型等多种经典牌阵。
- 🔀 **真实占卜流程**：包含提问、洗牌、切牌（选择切牌点）、凭直觉选牌的操作流程，模拟真实的塔罗占卜体验。
- 🖼️ **可视化揭示**：精美的牌面揭示动画（含正逆位区分），并提供详尽的基础牌义参考。
- 🤖 **AI 深度解读**：支持接入任何 OpenAI 兼容的 API（如 DeepSeek, GPT-4, Claude 等），根据用户问题与抽取的牌面进行个性化综合解读。
- 💾 **本地化配置**：API 设置及模型选择保存在浏览器本地，保护隐私且使用便捷。
- 📱 **响应式设计**：完美适配电脑与手机浏览器。


## 🚀 快速开始

1. **直接运行**：使用任何现代浏览器打开 `index.html` 即可开始。
2. **AI 配置** (可选)：
   - 点击页面顶部的 **⚙️ AI 设置**。
   - 输入你的 `BASE_URL` (例如 `https://api.deepseek.com/v1`) 和 `API_KEY`。
   - 点击“获取模型列表”并选择你想使用的模型。
   - 点击“保存配置”。
3. **开始占卜**：
   - 输入你想要咨询的问题。
   - 选择适合的牌阵。
   - 按照指引完成洗牌、切牌和选牌。
   - 查看牌面揭示，并点击“AI 整体解读”获取深度洞察。

## 🛠️ 技术栈

- **前端**：原生 HTML5, CSS3, JavaScript (ES6+)。
- **交互**：CSS3 Animations, SVG 矢量绘图。
- **数据存储**：Window.localStorage。
- **外部 API**：支持所有标准 OpenAI Chat Completions 协议的语言模型 API。
