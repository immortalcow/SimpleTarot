# SimpleTarot - 🔮 塔罗占卜工具

一个轻量级的、交互式的塔罗牌在线占卜工具，结合了传统的塔罗占卜流程与人工智能（AI）深度分析。

## ✨ 功能特点

- 🔮 **多种牌阵选择**：支持单张牌、三张牌、五张十字、二选一（V型）、六芒星、七张马蹄、凯尔特十字及关系牌型等多种经典牌阵，且均采用符合标准的几何网格布局。
- 🔀 **真实占卜流程**：包含提问、洗牌、切牌、凭直觉选牌（叠加排列视觉效果）的操作流程。
- 🖼️ **可视化揭示**：精美的 3D 翻牌逻辑，支持按顺序引导揭牌，提供详尽的基础牌义参考。
- 🤖 **AI 深度解读**：支持流式输出、深度思考（Reasoning）显示。接入所有 OpenAI 兼容 API。
- 📜 **占卜记录管理**：支持侧边栏查看历史占卜记录，支持中断恢复（记录翻牌状态）。
- 💾 **设置持久化**：API 设置及模型配置保存在浏览器 Cookie 中，页面刷新后自动恢复。
- 📱 **响应式设计**：完美适配电脑与手机浏览器，牌阵展示区域支持横向滚动。

## 📁 项目结构

```text
SimpleTarot/
├── index.html        # 应用主界面及逻辑入口
└── static/           # 静态资源目录

    └── js/

```

## 🚀 快速开始

1. **直接运行**：使用任何现代浏览器打开 `index.html` 即可开始。
2. **AI 配置** (可选)：
   - 点击页面顶部的 **⚙️ AI 设置**。
   - 输入你的 `BASE_URL` (例如 `https://api.deepseek.com/v1`) 和 `API_KEY`。
   - 点击“获取模型列表”并选择你想使用的模型。
   - 点击“保存配置”。
3. **开始占卜**：
   - 输入你想要咨询的问题。
   - 选择适合的牌阵。
   - 按照指引完成洗牌、切牌和选牌。
   - 查看牌面揭示，并点击“AI 整体解读”获取深度洞察。

## 🛠️ 技术栈

- **前端**：原生 HTML5, CSS3, JavaScript (ES6+)。
- **交互**：CSS3 Animations, SVG 矢量绘图。
- **数据存储**：浏览器 Cookie (主要用于 AI 配置) 及 Window.localStorage。
- **外部 API**：支持所有标准 OpenAI Chat Completions 协议的语言模型 API。
